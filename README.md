# TruthLens – AI Fake News Detection

TruthLens is a Machine Learning-based web application that predicts whether a news article is likely to be Fake or Real.

## Features
- Fake and Real news classification
- TF-IDF text vectorization
- Logistic Regression model
- Prediction confidence score
- Interactive Streamlit dashboard
- Prediction history

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- TF-IDF
- Logistic Regression
- Joblib

## Model Performance
Test accuracy: 98.99%

Note: This accuracy is measured on the dataset test split. It does not guarantee the correctness of real-world news.
